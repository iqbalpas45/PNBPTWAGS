🎯 INPUT HARIAN - STEP BY STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Pilih TANGGAL          → Sistem auto-detect kerja/libur + tarif
2. Pilih LOKET            → Loket 1 atau Loket 2
3. Isi NUSANTARA (WNI)    → Cash + QRIS + VA
4. Isi ASING (Mancanegara) → Cash + QRIS + VA
5. Lihat TARIF INFO       → Auto-display tarif hari ini
6. Klik SIMPAN TRANSAKSI  → Data masuk Dashboard + Cloud

🔄 SPLIT TRANSFER FORMAT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
TWAGS [Komponen] [HK/HL] [Tipe] [Count] ORG x [Tarif]

Contoh:
  TWAGS PNBP HK WNI 15 ORG x 10000
  TWAGS PTDID HL WNA 5 ORG x 23000

PNBP    = Penerimaan Negara Bukan Pajak
PTDID   = (Komponen lain)
HK/HL   = Hari Kerja / Hari Libur
WNI/WNA = Warga Negara Indonesia / Asing
ORG     = Organisasi/Satuan
